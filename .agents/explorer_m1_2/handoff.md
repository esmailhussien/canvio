## 2. Logic Chain

From the direct observations above, the technical requirements are deduced step-by-step:

### Step 1: Package Integration & Fastify Static Plugin Registration
- *Observation*: `apps/server/package.json` lacks `@fastify/static`; Fastify version is `^5.3.0`.
- *Reasoning*: Fastify 5 requires `@fastify/static@^8.1.0`. Registering `@fastify/static` provides high-performance static asset streaming, HTTP range requests, ETag/conditional caching, and decorates Fastify replies with `reply.sendFile()`.
- *Path Resolution*: In TypeScript ESM, `import.meta.url` points to `apps/server/src/combined-server.ts` in development, or `apps/server/dist/combined-server.js` in production. Resolving `path.resolve(path.dirname(fileURLToPath(import.meta.url)), '../../web/dist')` accurately resolves to `apps/web/dist` in both source and compiled Docker layouts. Providing `process.env.CANVIO_STATIC_DIR` allows explicit override.

### Step 2: Content-Security-Policy Scoping Strategy
- *Observation*: `apps/server/src/http.ts` applies `default-src 'none'` globally on all requests.
- *Reasoning*: Security defense-in-depth requires that headless REST/AI endpoints remain strictly locked down (`default-src 'none'; frame-ancestors 'none'; form-action 'none'`). However, frontend HTML pages and static assets must allow the resources Canvio needs to render and synchronize.
- *Policy Formulation*:
  - API routes (`pathname === '/api' || pathname.startsWith('/api/')`): Retain strict API CSP.
  - Frontend routes & assets: Apply production-safe CSP:
    - `default-src 'self'`
    - `script-src 'self' 'unsafe-inline'` (required for `<head>` theme script and JSON-LD structured data)
    - `style-src 'self' 'unsafe-inline'` (required for Leaflet CSS and dynamic canvas styles)
    - `img-src 'self' data: blob: https://tile.openstreetmap.org https://*.tile.openstreetmap.org https://server.arcgisonline.com https://quickchart.io` (required for canvas export, Leaflet markers, OSM street tiles, ArcGIS satellite/hybrid tiles, and QuickChart QR codes)
    - `font-src 'self' data:`
    - `connect-src 'self' ws: wss: https:` (required for REST endpoints, real-time Yjs WebSockets on both `ws:` and `wss:`, and external HTTPS services)
    - `frame-ancestors 'none'` (retains clickjacking protection)
    - `form-action 'self'`

### Step 3: Dynamic Runtime Config Generation (`GET /canvio-config.js`)
- *Observation*: Vite builds a static `canvio-config.js` into `dist/` containing an empty object. At runtime, the browser needs to know where to open its WebSocket connection without hardcoding ports or hostnames.
- *Reasoning*: In a unified single-node container, the WebSocket server is attached to the same HTTP server on the same port. However, the external port or hostname may vary (e.g. `localhost:4000`, `localhost:8080`, custom domain, or reverse proxy with SSL termination).
- *Inference*: Fastify must register a high-priority route `GET /canvio-config.js` that emits dynamic JavaScript:
  ```javascript
  reply.header('Cache-Control', 'no-cache, no-store, must-revalidate');
  reply.header('Pragma', 'no-cache');
  reply.header('Expires', '0');
  reply.type('application/javascript; charset=utf-8');
  return `window.CANVIO_CONFIG = {
    apiUrl: ${JSON.stringify(process.env.VITE_API_URL || process.env.CANVIO_API_URL || '')},
    wsUrl: ${JSON.stringify(process.env.VITE_WS_URL || process.env.CANVIO_WS_URL || '')} || ((window.location.protocol === 'https:' ? 'wss:' : 'ws:') + '//' + window.location.host),
  };`;
  ```
  This guarantees zero-configuration client connection: the browser automatically deduces whether to use `ws://` or `wss://` and targets the exact host/port where the HTML was served from.

### Step 4: Routing Hierarchy & Not-Found Handler Architecture
- *Observation*: `combined-server.ts` currently mounts `GET /` to return JSON, preventing `dist/index.html` from serving as the homepage.
- *Reasoning*:
  1. The root route `GET /` must serve the frontend homepage. Moving the API index to `GET /api` leaves `/` free for `@fastify/static`.
  2. When requests arrive for clean URLs without `.html` extensions (such as `/how-it-works` or `/updates/...`), or for dynamic SPA routes (such as `/w/:id`), `@fastify/static` does not match an exact file and invokes `reply.callNotFound()`.
- *Inference*: Fastify's `app.setNotFoundHandler()` must implement a 4-tier resolution pipeline:
  - **Tier 1 (API 404s)**: If `pathname === '/api' || pathname.startsWith('/api/')`, return HTTP 404 JSON `{ error: 'NOT_FOUND', message: '...', statusCode: 404 }`. Never return HTML for API requests.
  - **Tier 2 (Asset 404s)**: If `pathname` starts with `/assets/` or ends with a static file extension (`.js`, `.css`, `.png`, etc.), return HTTP 404 JSON to prevent browsers from parsing HTML fallbacks as JavaScript.
  - **Tier 3 (SSG Pre-rendered Routes)**: Sanitize pathname to prevent directory traversal. Check if `path.join(DIST_DIR, cleanPath, 'index.html')` exists. If so, stream it with `reply.type('text/html; charset=utf-8').sendFile(...)`.
  - **Tier 4 (SPA Fallback)**: For any other GET/HEAD page requests (e.g. `/w/:boardId`, `/w/new`), stream `dist/index.html` with `reply.type('text/html; charset=utf-8').sendFile('index.html')`.

## 3. Caveats

1. **Build Order Prerequisite**:
   - `apps/web/dist` is created during `npm run build` (specifically `vite build && node ../../scripts/prerender.mjs`). If `combined-server.ts` is started prior to building `@canvio/web`, the server should gracefully log a warning and fall back to API-only mode without crashing on startup.
2. **Directory Traversal Protection**:
   - In `setNotFoundHandler`, user-supplied URLs must be sanitized via `path.normalize()` and stripped of leading `..` and slashes before probing candidate SSG file paths on disk.
3. **HTTP Method Filtering in SPA Fallback**:
   - SPA fallback should strictly apply only to `GET` and `HEAD` requests. A `POST`, `PUT`, or `DELETE` request sent to an unmatched route must return a 404 JSON response rather than `index.html`.
4. **WebSocket Port Collision**:
   - When running `combined-server.ts`, standalone WebSocket server `ws-server.ts` (port 4001) is not used. The unified server binds both HTTP and WS on `PORT` (default 4000).

```typescript
// Full proposed implementation of apps/server/src/combined-server.ts

/**
 * Combined HTTP + WebSocket server for production deployment.
 * Merges the Fastify API, static frontend serving, and Yjs WebSocket server
 * on a single port for self-contained single-node production deployment.
 */
import Fastify from 'fastify';
import cors from '@fastify/cors';
import fastifyStatic from '@fastify/static';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import fs from 'node:fs';
import { WebSocketServer } from 'ws';
// @ts-ignore
import ywsUtils from 'y-websocket/bin/utils';
import dotenv from 'dotenv';
import { boardRoutes } from './routes/boards.js';
import { aiRoutes } from './routes/ai.js';
import { telemetryRoutes } from './routes/telemetry.js';
import { createFilePersistence } from './storage/yPersistence.js';
import { ALLOWED_CORS_HEADERS, createCorsOriginGuard, readPositiveIntEnv } from './security.js';
import { authorizeWebSocketBoard, getBoardIdFromWsRequest } from './wsAccess.js';
import { FASTIFY_OPTIONS, registerErrorHandler, registerSecurityHeaders } from './http.js';
import { getReadiness } from './health.js';

dotenv.config();

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const DEFAULT_DIST_DIR = path.resolve(__dirname, '../../web/dist');
const DIST_DIR = process.env.CANVIO_STATIC_DIR || DEFAULT_DIST_DIR;

const { setupWSConnection, setPersistence } = ywsUtils;
setPersistence(createFilePersistence());

const PORT = parseInt(process.env.PORT || '4000', 10);

const app = Fastify(FASTIFY_OPTIONS);
registerErrorHandler(app);
registerSecurityHeaders(app);

app.register(cors, {
  origin: createCorsOriginGuard(),
  allowedHeaders: ALLOWED_CORS_HEADERS,
});

// Dynamic runtime configuration route for zero-config client port binding
app.get('/canvio-config.js', async (_request, reply) => {
  reply.header('Cache-Control', 'no-cache, no-store, must-revalidate');
  reply.header('Pragma', 'no-cache');
  reply.header('Expires', '0');
  reply.type('application/javascript; charset=utf-8');

  const configuredApiUrl = process.env.VITE_API_URL || process.env.CANVIO_API_URL || '';
  const configuredWsUrl = process.env.VITE_WS_URL || process.env.CANVIO_WS_URL || '';

  return [
    'window.CANVIO_CONFIG = {',
    `  apiUrl: ${JSON.stringify(configuredApiUrl)},`,
    `  wsUrl: ${JSON.stringify(configuredWsUrl)} || ((window.location.protocol === 'https:' ? 'wss:' : 'ws:') + '//' + window.location.host),`,
    '};',
    '',
  ].join('\n');
});

// Register static frontend serving if compiled web dist exists
if (fs.existsSync(DIST_DIR)) {
  app.register(fastifyStatic, {
    root: DIST_DIR,
    prefix: '/',
    decorateReply: true,
    serve: true,
    wildcard: true,
  });
} else {
  app.log.warn(`Static frontend directory not found at ${DIST_DIR}. Static serving disabled.`);
}

// API Metadata endpoint relocated from '/' to '/api' to allow '/' to serve frontend
app.get('/api', async () => ({
  name: 'Canvio Combined API + Collaboration Server',
  status: 'online',
  version: '1.0.0',
  endpoints: {
    boards: '/api/boards',
    ai: '/api/ai',
    telemetry: '/api/telemetry/events',
    health: '/health',
  },
}));

app.get('/health', async () => ({ status: 'healthy', timestamp: new Date().toISOString() }));

app.get('/health/ready', async (_request, reply) => {
  try {
    return await getReadiness();
  } catch (error) {
    app.log.error({ err: error }, 'Readiness check failed');
    return reply.code(503).send({ status: 'not_ready', storage: 'unavailable' });
  }
});

app.register(boardRoutes, { prefix: '/api/boards' });
app.register(aiRoutes, { prefix: '/api/ai' });
app.register(telemetryRoutes, { prefix: '/api/telemetry' });

// Comprehensive 404, SSG prerender route, and SPA fallback handler
app.setNotFoundHandler(async (request, reply) => {
  const pathname = (request.url || '').split('?')[0];

  // 1. Always preserve 404 JSON for API routes
  if (pathname === '/api' || pathname.startsWith('/api/')) {
    return reply.code(404).send({
      error: 'NOT_FOUND',
      message: `API route not found: ${request.method} ${pathname}`,
      statusCode: 404,
    });
  }

  // 2. Only GET and HEAD requests should attempt HTML / SPA resolution
  if (request.method !== 'GET' && request.method !== 'HEAD') {
    return reply.code(404).send({
      error: 'NOT_FOUND',
      message: `Cannot ${request.method} ${pathname}`,
      statusCode: 404,
    });
  }

  // 3. Unmatched static asset requests return 404 JSON instead of HTML fallback
  const isAsset = pathname.startsWith('/assets/') || /\.[a-zA-Z0-9]+$/.test(pathname);
  if (isAsset) {
    return reply.code(404).send({
      error: 'NOT_FOUND',
      message: `Asset not found: ${pathname}`,
      statusCode: 404,
    });
  }

  // 4. SSG & SPA fallback resolution
  if (fs.existsSync(DIST_DIR)) {
    const cleanPath = path
      .normalize(pathname)
      .replace(/^(\.\.[\/\\])+/, '')
      .replace(/^[/\\]+|[/\\]+$/g, '');

    if (cleanPath) {
      const posixPath = cleanPath.split(path.sep).join('/');
      const ssgRelativePath = `${posixPath}/index.html`;
      const ssgCandidatePath = path.join(DIST_DIR, ssgRelativePath);

      if (fs.existsSync(ssgCandidatePath) && fs.statSync(ssgCandidatePath).isFile()) {
        return reply.type('text/html; charset=utf-8').sendFile(ssgRelativePath);
      }
    }

    const spaIndexPath = path.join(DIST_DIR, 'index.html');
    if (fs.existsSync(spaIndexPath) && fs.statSync(spaIndexPath).isFile()) {
      return reply.type('text/html; charset=utf-8').sendFile('index.html');
    }
  }

  return reply.code(404).send({
    error: 'NOT_FOUND',
    message: `Route not found: ${request.method} ${pathname}`,
    statusCode: 404,
  });
});

// WebSocket hardening: bound message size and connection counts
const WS_MAX_PAYLOAD = readPositiveIntEnv('CANVIO_WS_MAX_PAYLOAD_KB', 2048, 64, 16_384) * 1024;
const WS_MAX_CONNECTIONS = readPositiveIntEnv('CANVIO_WS_MAX_CONNECTIONS', 200, 10, 10_000);
const WS_MAX_PER_IP = readPositiveIntEnv('CANVIO_WS_MAX_PER_IP', 20, 1, 1_000);

const wss = new WebSocketServer({ server: app.server, maxPayload: WS_MAX_PAYLOAD });

let activeConnections = 0;
const connectionsPerIp = new Map<string, number>();

wss.on('connection', async (conn, req) => {
  if (activeConnections >= WS_MAX_CONNECTIONS) {
    conn.close(1013, 'Server at connection capacity');
    return;
  }

  const forwardedFor = typeof req.headers['x-forwarded-for'] === 'string'
    ? req.headers['x-forwarded-for'].split(',')[0].trim()
    : null;
  const peerIp = forwardedFor || req.socket.remoteAddress || 'unknown';
  const currentForIp = connectionsPerIp.get(peerIp) || 0;
  if (currentForIp >= WS_MAX_PER_IP) {
    conn.close(1013, 'Too many connections from this address');
    return;
  }

  const boardId = getBoardIdFromWsRequest(req);

  try {
    const access = await authorizeWebSocketBoard(req, boardId);
    if (!access.ok) {
      conn.close(access.code, access.reason);
      return;
    }

    activeConnections += 1;
    connectionsPerIp.set(peerIp, currentForIp + 1);
    let released = false;
    const releaseConnection = () => {
      if (released) return;
      released = true;
      activeConnections -= 1;
      const remaining = (connectionsPerIp.get(peerIp) || 1) - 1;
      if (remaining <= 0) connectionsPerIp.delete(peerIp);
      else connectionsPerIp.set(peerIp, remaining);
    };
    conn.on('close', releaseConnection);
    conn.on('error', releaseConnection);

    console.log(`[WS] Client connected → board: ${boardId}`);
    setupWSConnection(conn, req, { docName: boardId });
  } catch (err) {
    console.error(`[WS] Failed to authorize board ${boardId}`, err);
    conn.close(1011, 'WebSocket authorization failed');
  }
});

const start = async () => {
  try {
    await app.listen({ port: PORT, host: '0.0.0.0' });
    console.log(`🚀 Canvio Combined API + Collaboration Server running on port ${PORT}`);
  } catch (err) {
    app.log.error(err);
    process.exit(1);
  }
};

start();
```

### 5.4 SSG and SPA Route Resolution Verification
```bash
# 1. Homepage returns index.html
curl -i http://localhost:4000/

# 2. SSG Route returns prerendered HTML with SEO title and Schema.org
curl -i http://localhost:4000/how-it-works
curl -i http://localhost:4000/updates/laser-pointer-for-live-guidance

# 3. Dynamic SPA board route falls back to index.html with 200 OK
curl -i http://localhost:4000/w/production-validation-board

# 4. Nonexistent API route returns 404 JSON, NOT HTML
curl -i http://localhost:4000/api/nonexistent-endpoint
# Expected: HTTP 404, Content-Type: application/json, body: {"error":"NOT_FOUND", ...}

# 5. Nonexistent asset returns 404 JSON, NOT HTML
curl -i http://localhost:4000/assets/nonexistent.js
# Expected: HTTP 404
```

### 5.5 Invalidation Conditions
The specification should be re-evaluated if:
- Fastify is downgraded to v4 (which would require `@fastify/static@v6/v7` instead of v8).
- Additional third-party media or tile domains (e.g. Mapbox, Google Maps) are introduced into the whiteboard canvas.
